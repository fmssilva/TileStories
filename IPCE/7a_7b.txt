46 - No jogo Hi-Lo o computador pensa num número inteiro secreto no intervalo [0,1023]. Depois o utilizador tenta adivinhar qual é esse número, no menor número de jogadas que conseguir.
O programa gera internamente um número secreto entre 0 e 1023, e depois vai lendo as tentativas do utilizador. O computador vai respondendo ">", "<" ou "=". Portanto, o programa vai informando o utilizador se a tentativa corrente é maior, menor ou igual ao que o segredo. Quando surge a resposta "=", o programa acaba, claro.

Note que o programa vai precisar de ler uma sequência não vazia de inteiros até ocorrer a condição de vitória. O comprimento desta sequência de inteiros é indeterminado. Só sabemos que é maior do que zero.

Este tipo de situação foi estudado na aula teórica 04a. Para se inspirar, eis as duas soluções que foram vistas para somar uma sequência não vazia de inteiros com comprimento indeterminado:

END_MARK = -1

def read_and_add() -> int:
    """ Read and add a sequence of integers with unknown length. """
    sum = 0
    v = int(input("> "))     # lê (fora do ciclo)             
    while v != END_MARK:     # testa
        sum += v             # soma
        v = int(input("> ")) # lê (dentro do ciclo)  
    return sum
END_MARK = -1

def read_and_add() -> int:
    """ Read and add a sequence of integers with unknown length. """
    sum = 0
    while True:
        v = int(input("> "))  # lê   
        if v == END_MARK:     # testa                  
            break
        sum += v              # soma
    return sum

47 - Programe agora o jogo Hi-Lo com troca de papéis: desta vez é o utilizador a escolher o número secreto e o computador a tentar adivinhar. Agora é mais difícil.
Eis os detalhes da iteração com o utilizador:

O programa começa por escrever: "Pense num número secreto entre 0 e 1023.". Nessa altura o utilizador pensa num número secreto (mas fica calado e não o diz ao computador).
Depois, durante o jogo, o programa vai tentando adivinhar o número e vai perguntando: "A minha tentativa é X. Diga-me se o número secreto é maior (>), menor (<) ou igual (=) ? ".
No final do jogo há duas reações possíveis do programa: "Viva! Acertei em N tentativas! O número secreto era X!" ou, "Você é batoteiro!".
Ainda mais um detalhe. Desta vez queremos validação do input! Quando o programa pede um dos símbolos (>) (<) ou (=), se o utilizador introduzir um símbolo errado, o programa deve repetir a pergunta. Se o utilizador voltar a enganar-se, o programa repete a pergunta. E assim sucessivamente, até finalmente o utilizador dar uma resposta com sentido.
Este programa só precisa de usar inteiros e carateres; não precisa de listas, nem de manipular strings, etc. A novidades são só a programação de dois ciclos while: (1) o ciclo de leitura com validação; (2) o ciclo que efetua a condução do jogo.

Note que há uma diferença importante no processamento de matrizes, quando comparado com o processamento de listas:

Com as listas é frequente ir fazendo crescer as listas em função das nossas necessidades;
Com matrizes, pelo contrário, trabalhamos quase sempre com matrizes de dimensões fixas - em parte devido à natureza dos problemas que queremos resolver, mas também devido ao facto de, por exemplo, ao fazer crescer uma linha, a matriz deixa de ser matriz.
Na aula teórica 07a, foi introduzido uma coleção de operações básicas (create, is_valid, nrows, is_empty, ncols, row, col, input_int_matrix), que facilitam o tratamento de matrizes com dimensão fixa. Essas operações são oferecidas no código mais abaixo, pois vai precisar de as usar.

type IMatrix = list[list[int]]

def sum(m1: IMatrix, m2: IMatrix) -> IMatrix:
    """ New matrix with all the corresponding elements of m1 and m2 added.
        Precondition: is_valid(m1) and is_valid(m2)
           and nrows(m1) == nrows(m2) and ncols(m1) == ncols(m2)
    """
    nr, nc = nrows(m1), ncols(m1)
    m3 = create(nr, nc, 0)
    for i in range(nr):
        for j in range(nc):
            m3[i][j] = m1[i][j] + m2[i][j]
    return m3

def create(nr: int, nc: int, value: any) -> GMatrix:
    """ Create and initialize a matrix with nr rows and nc columns.
        Precondition: nr >= 0 and nc >= 0
    """
    m = [None]*nr         # cria espaço para as linhas
    for i in range(nr):   # preenche as várias linhas
        m[i] = [value]*nc
    return m

def is_valid(m: GMatrix) -> bool:
    """ Check if all the lines have the same length. """
    nr = len(m)
    for i in range(nr-1):  # verifica se todas as linhas têm igual comprimento
        if len(m[i]) != len(m[i+1]):
            return False
    return True

def nrows(m: GMatrix) -> int:
    """ Number of rows of the matrix
        Precondition: is_valid(m)
    """
    return len(m)             # número de linhas

def is_empty(m: GMatrix) -> int:
    """ Is the matrix empty? """
    return nrows(m) == 0      # testa se matriz vazia 

def ncols(m: GMatrix) -> int:
    """ Number of columns of the matrix.
        Precondition: is_valid(m)
    """
    if is_empty(m):           # a matriz vazia tem 0 colunas
        return 0
    else:
        return len(m[0])      # número de colunas é o comprimento duma linha

def row(m: GMatrix, i: int) -> GList:
    """ Get the row i of the matrix.
        Precondition: is_valid(m) and i in range(nrows(m))
    """
    return m[i].copy()      # faz cópia porque col também faz cópia

def col(m: GMatrix, j: int) -> GList:
    """ Get the column j of the matrix.
        Precondition: is_valid(m) and j in range(ncols(m))
    """
    col = []
    for r in m:             # acumula os vários elementos da coluna j
        col.append(r[j])
    return col
