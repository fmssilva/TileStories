# SOURCES -- every file in `content/`

> **This copy sits next to the imported media** (`CardMedia/`, P1b). The paths below are the same here as in the gather folder
> `proj_guides/detail_card/content/`, except these rows, whose files stayed THERE and are not in the build: `images/castle_peacock.jpg`
> (gathered, not used by the wall), the narration scripts `audio/*.txt`, `text/` and `tools/`. Checked against the folder 2026-10-22
> (P1b part 2): every other row's file is here, and every file here has its row (`placeholder_hero.png`, `images/night_hero.png`,
> `lamp_tone.*` and `models/` are this project's own fixtures, listed in `README.txt`).

Retrieved 2026-10-22 by the P1a Worker. One row per file. Author and licence come from the file's Commons record (API `extmetadata`),
not from memory. "Changes" says what was done to the original. Nothing here is "all rights reserved" and nothing comes from a search
engine's image results: every picture, the video clips and the map tiles have a licence page (the Source URL).

**This does NOT clear the ship blocker of `_3.1`** (`_3.3` "Before this domain is planned" point 2). It replaces the placeholders on the
LivingRoom test wall with freely licensed, correctly attributed material. A build given to anyone else still needs the attribution lines
below shown in the app (CC BY / CC BY-SA require them) and a final licence check of each file.

Licence notes: CC BY needs the author named; CC BY-SA also needs derivatives (crops, resizes) shared under the same licence if the
picture is distributed; CC BY-SA 3.0 / 2.0 files are used as the licence of the original says. Public-domain rows are old artworks
(PD-old / PD-Art on Commons: a faithful photo of a 2D work that is out of copyright).
