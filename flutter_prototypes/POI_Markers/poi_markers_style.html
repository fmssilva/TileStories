Implementation Guide for AI Agent

1 · Marker Anatomy — Layer Stack

Each POI widget is composed of exactly 4 layers, rendered bottom-to-top:

  • Layer 0 — Pulse rings (2×): Animated expanding circles. Only rendered when marker is in SELECTED state. border-radius: 50%, border: 1–1.5px solid [type-accent-colour], opacity animated 0.7→0 with scale 0.9→1.7 over 2.4s. Second ring offset by 1.2s delay.
  • Layer 1 — Body circle: The main shape. Background = deep-tinted type colour (very dark, ~15% lightness). Border = destruction colour + destruction style. Inner glass highlight via ::after pseudo-element with radial-gradient top-left.
  • Layer 2 — Icon: Emoji or white-stroke SVG. Sits centred inside body. Hidden at Scale 1–2. Always renders at high contrast against dark bg.
  • Layer 3 — Label pill: Positioned absolutely outside the body. Semi-transparent dark bg. Rules below govern when it shows and where it anchors.

4 · Destruction Encoding — Border

The border encodes 3 simultaneous signals: colour, style, and opacity/filter. All three must degrade together as destruction increases.

Range Label Colour Style Opacity Grayscale filter
0% Intact #22c55e solid 1.0 0%
20% Minor #84cc16 solid 1.0 0%
40% Partial #eab308 dashed (5px gap 4px) 1.0 0%
60% Heavy #f97316 dashed (3px gap 3px) 1.0 0%
80% Ruins #ef4444 dotted 0.72 25%
100% Gone #991b1b dotted 0.38 55%

Border width: 2dp at S1, 2.5dp at S2–S3, 3dp at S4–S5. The outer box-shadow at S3+ adds a soft glow matching the border colour at 35–45% opacity.

5 · Label Rules

  • Background: rgba(6,5,3, 0.82) with backdrop-filter: blur(8px). Selected: rgba(8,6,2, 0.92) with border: 1px solid rgba(201,151,58, 0.25).
  • Typography: DM Sans 10dp, weight 500, colour rgba(240,230,204, 0.88). Selected: weight 600, opacity .96. Max 2 lines — truncate with ellipsis after that.
  • Positioning default: Anchor bottom-left corner of label to top-right of marker. Offset: +4dp right, -4dp above centre.
  • Edge detection — flip rules: If marker x > 75% of map width → flip label left (right: 60%, left: auto). If marker y > 80% of map height → flip label above (bottom: auto, top: 55%). Run edge check on every render frame during pan.
  • Collision management: Labels use z-index: parent + 1. When two labels overlap, hide the lower-priority one (priority = scale level, then destruction % ascending — intact POIs more important). At S1–S2, labels are always hidden. At S3, show only on hover/tap. At S4+, always show but subject to collision suppression.
  • Selected label: Always shown regardless of collision. Gold border tint. Sits at z-index 101 (above all non-selected markers).
  • Animation: Labels fade in 160ms ease-out on appearance. No fade on position changes (snappy flip).

6 · Selected State — Full Spec

  • Shape: border-radius morphs from 50% → 30% (squircle). Animate over 300ms ease.
  • Size: Scale from current size → 64dp diameter. Animate 280ms ease.
  • Float: CSS animation translateY(0px) → translateY(-3px) → translateY(0px) over 3s ease-in-out, infinite. Do not combine with tap scale animation — wait for tap to finish first.
  • Shadow: Add box-shadow: 0 8px 28px rgba(0,0,0, 0.65), 0 0 0 2px rgba(255,255,255, 0.12).
  • Pulse rings: 2 concentric rings, same colour as type accent. Ring 1: 1.5px border, 2.4s cycle. Ring 2: 1px border, same cycle offset 1.2s. Both animate opacity 0.7→0 and scale 0.9→1.7. Start from radius = marker radius + 8dp.
  • z-index: 100 (above everything except modals).
  • Only one marker selected at a time. Deselect on: tap another marker, tap map background, tap back button.
  • Deselection: Reverse all animations. Scale back to S4 (if was S4 before selection). Border-radius returns to 50%. Float and pulse rings stop immediately (do not wait for cycle end).

7 · Z-Index & Depth Management

  • Map tile layer: z-index: 0
  • S1 markers: z-index: 10
  • S2 markers: z-index: 20
  • S3 markers: z-index: 30
  • S4 markers: z-index: 40
  • Hovered marker: z-index: 50 (temporary, via JS class)
  • Selected marker: z-index: 100
  • Legend panel: z-index: 200
  • Bottom sheet / modal: z-index: 300
  • Within same scale: Higher destruction % = lower z-index (intact POIs sit above ruins — ruins are more ghostly, intact ones more present).
  • Labels always have z-index = parent + 1. This means label of a z:40 marker = 41. Since labels are position: absolute children of the marker widget, they inherit the stacking context correctly in Flutter.

8 · Flutter Implementation Notes

  • Use flutter_map with MarkerLayer. Each marker is a GestureDetector wrapping a custom PoiMarkerWidget.
  • Border-style (solid/dashed/dotted) on a circle: use CustomPainter — draw dashes manually with canvas.drawArc or a dashed path. CSS border-style has no direct Flutter equivalent.
  • Emoji icons: use Text(emoji, style: TextStyle(fontSize: X)) inside the circle. Apply colorFilter if grayscale needed. Emoji size scales with marker size.
  • Squircle morph: animate BorderRadius via AnimatedContainer or TweenAnimationBuilder<BorderRadius>.
  • Float animation: AnimationController with Curves.easeInOut, translate Y with Transform.translate.
  • Pulse rings: two AnimatedBuilder widgets with Tween<double> for opacity and scale. Wrap in Stack behind the body circle.
  • Label flip: compute MarkerAnchorPoint in build() based on the marker's projected screen position. Use MapController.latLngToScreenPoint() to get x/y, then apply flip rules.
  • Collision detection: maintain a List<Rect> of visible label rects. On each camera move, recompute and suppress overlapping labels from lowest to highest priority.
  • Performance: at S1/S2 the marker is a simple Container with BoxDecoration. Avoid painting pulse rings at S1/S2. Use RepaintBoundary around each marker widget.
