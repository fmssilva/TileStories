3:// Returns the four building damage levels the authoring tool seeds into a
4:// wall's config when it has no badge_categories yet. Editor-only data --
5:// runtime reads whatever config.json provides, never these defaults.
6://
7:// Sibling factory to DefaultCategoryStyles.cs (see _5.3_Default_Icons.md
8:// section 1). Shared pattern by naming convention, not a generic abstraction,
9:// because badge rows and category rows use different entry types.
