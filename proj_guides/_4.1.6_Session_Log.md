# World Design (4.1.6) -- version log of the World Editor Lab (v6 to v20)

The version history of the World Editor Lab (`_4.1.2_Prototype/`): for each version, what changed and why, with the test counts
it was published with. The guides (`_4.1.3` to `_4.1.12`) state what IS; this log is the only place that says how it got there.
v6 was the first version with the App tab; v7 is where the source was split into `lab_src/`. The Lab is one artifact,
republished for every version. After a round: add its entry here, update the guides, run the safety net
(`_4.1.2_Prototype/lab_src/README.md`).

## Versions

## Decisions
- Precision in cm · one outward offset · fills none / tint / gradient / pattern / media · six Wall Life kinds · triggers (Lapse
  later) · no attention budget · anchors are normal shapes with a quiet style + Focus › Appear · media: the style says how, the
  shape says which file · video: loop or on tap (a style option).
- Editor organisation: App · Global Scene in 6 groups · Specific Marker · Experiences · Detail Card · Guide.
- The Tag is built from Detail Card UI Toolkit blocks anchored to the POI; the tap result offers every option, per level.
- Map / geo-reference and capture & share: the places are kept, built later.
- Actions: the types are code; their settings sit next to their content; the wall layout is in App, the screen layout in Detail
  Card, Azu in Guide.
- 3D: any format in the Editor, a prefab or GLB at runtime. Label inside Tag. Wall-wide moments in Experiences.
