# Human-in-the-Loop Tests - Select, Filter & Search (Block 6 Tier 2)

## Setup Instructions
1. Build development version of the app with MockLocalizationProvider enabled
2. Install on Android/iOS device
3. Launch app and wait for localization (should be immediate with mock provider)
4. Ensure LivingRoom content is loaded (18 POIs with 3 hierarchy levels)

## Verification Checklist
Perform each action and verify the expected behavior:

### 1. Search & Filter Authoring Persistence (Desktop)
- [ ] Launch POI Authoring Tool (Shift+P)
- [ ] Open Search & Filter foldout
- [ ] Change search_index_strategy from "keyword_ranked" to "weighted_fields"
- [ ] Edit a weight field value (e.g., weight_name from 3 to 5)
- [ ] Save All to JSON
- [ ] Reload config
- [ ] Verify strategy and weight values persisted correctly

### 2. Basic Search Functionality
- [ ] Open search overlay (magnifying glass in nav bar)
- [ ] Enter "templo" or a common POI name fragment
- [ ] Verify results list updates with matching POIs
- [ ] Tap a result
- [ ] Verify DetailCard appears showing POI name and close button
- [ ] Tap close button or background
- [ ] Verify DetailCard dismisses

### 3. Filter Interaction
- [ ] In search overlay, open filter tray
- [ ] Verify category facets are displayed
- [ ] Select a category filter
- [ ] Verify results list filters to only that category
- [ ] Clear the filter
- [ ] Verify all POIs return to results list

### 4. Minimap View
- [ ] Switch result view to "minimap" mode
- [ ] Verify minimap displays with POI dots
- [ ] Tap a dot on the minimap
- [ ] Verify selection transfers to results list and camera view
- [ ] Switch back to "list" view
- [ ] Verify list view restored

### 5. Camera Highlight View
- [ ] Switch result view to "camera_highlight" mode
- [ ] Verify AR markers are visible in camera view
- [ ] Enter a search query
- [ ] Verify matching markers are highlighted in camera view
- [ ] Clear search
- [ ] Verify highlight clears

### 6. Zoom-on-Select
- [ ] Navigate camera to an area with dense markers (if possible)
- [ ] Tap a marker in the dense area
- [ ] Verify camera smoothly zooms in on selection
- [ ] Tap an isolated marker
- [ ] Verify NO zoom occurs (isolated marker threshold not met)

### 7. Selection Highlight
- [ ] Ensure multiple markers are visible on screen
- [ ] Tap one marker
- [ ] Verify other markers dim (alpha reduced) while selected marker stays bright
- [ ] Tap a different marker
- [ ] Verify highlight shifts correctly
- [ ] Tap background or same marker
- [ ] Verify all markers return to full brightness

### 8. Voice Search (If Enabled)
- [ ] Ensure voice_search_enabled is true in config
- [ ] Tap microphone button in search overlay
- [ ] Verify permission prompt appears (first time only)
- [ ] Speak a POI name clearly
- [ ] Verify results update with matching POIs
- [ ] Tap a voice result
- [ ] Verify selection works as expected

### 9. Performance & Responsiveness
- [ ] Search for terms updates results within 1 second
- [ ] Filter toggles apply within 500ms
- [ ] View mode switches are instant
- [ ] Zoom animations are smooth (60fps)
- [ ] Highlight/dim transitions are smooth

### 10. Edge Cases
- [ ] Search for a term that matches nothing
- [ ] Verify "No results" message displays
- [ ] Verify relax-suggestion appears if applicable
- [ ] Search for a partial term (e.g., "tem" should match "templo")
- [ ] Verify suggestions appear as you type
