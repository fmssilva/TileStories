POI Marker Design Options

A second pass after two corrections: the status ring must never fully disappear — a faint-to-invisible ring reads as "no data," which collides with the real "no status axis" case (the mural wall). And before picking a winner, this treats the secondary axis as wall-defined data that isn't always destruction — some walls need an ordinal scale, others need an open categorical set, so the marker system has to support both shapes, not just the one this project happens to need first.

Changed since v1: status ring redesigned so every level (including 100% Gone) stays fully opaque and legible — gradation now comes from dash rhythm + a warm-gold→rust colour drift, never from fading out. Added an explicit "no status axis" swatch next to the spectrum so the two different kinds of "nothing" are visually distinguishable. Replaced the single corner-badge option with four badge compositions to compare placement, and added a categorical (non-ordinal) demo axis — painting style — to prove the badge slot generalises beyond destruction. What the second axis actually varies wall to wall
Per the framework rule, neither axis is a fixed enum — each wall defines its own category values and, if it has one at all, its own secondary axis. The shape that axis needs depends on whether it's ordinal (has a natural order, so a gradient/ramp communicates it) or categorical (an open set with no inherent order, so it needs its own colour + icon per value, same as the primary category does).

This is why System C (same-hue modulation) can't be the only answer. "Draining a hue toward black" only means something for a quantity that has a direction — destruction, endangerment, rarity. It has no sensible reading for painting style, which has no "more" or "less." A badge is the one mechanism that works for both, because it reuses exactly the primary category's own trick (its own colour + its own icon) at a smaller scale — so the question below isn't "is a badge good," it's "where does the badge sit so it reads cleanly instead of fighting the main icon."

Where this leaves the decision

For an ordinal-only wall (Panorama/Chafariz today), System A (ring) or System C (same-hue fade) both work now that the ring never goes invisible — C is the more elegant one and the one that supports your future colour-priority toggle for free, at the cost of needing a bit more math per category (hue-drain interpolation) instead of one fixed lookup table.

For a wall that also needs a categorical secondary axis (mural species/habitat, graffiti style), a badge is structurally required, not optional — the only open question is placement. Inset keeps the marker's outer silhouette a clean circle (best for a dense, noisy AR view) and is the current default in the interactive test below; underlay is the quietest but risks being missed entirely; outside and ring-mounted are both more assertive, which is worth testing against a real photo before ruling out. Try each against the live 15-marker simulation — the composition should be a one-line config swap in the real renderer either way, so nothing here is a one-way door.
