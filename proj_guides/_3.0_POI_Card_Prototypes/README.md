# POI Detail Card -- design prototypes (2026-09-26)

The design canvas made while planning `_3.1` (blocks), `_3.2` (navigation) and `_3.3` (styles). Reference only: the guides
are the spec; these boards show the intended look and the options that were considered.

- Live, browsable version (the canvas with all boards): https://claude.ai/artifact/5Jfe1sZcYnUnqTTYhknPFd
- The `.dc.html` files here are the board sources. They need the canvas runtime (`support.js`) to render, so open the link
  above to view them; keep these files as the editable source and for diffing future design changes.

| Board | Content |
|---|---|
| Main | The full POI card, every block in sequence |
| Layouts | Card presentation modes and block states |
| Specs | Block config schema (Unity) |
| Ontology | Block families, kinds, lenses, facets |
| Navigation | 24 navigation element patterns (`_3.2`) |
| NewBlocks | New blocks from the TileStories plan (43 variants) |
| Variants | Variants of existing blocks (20) |
| Lifecycle | Single-POI card flow (bottom sheet) |
| Themes | 3 styles x standard / sunlight high contrast (`_3.3`) |
| EditorTab | POI Editor card tab (tokens, stack, overrides) |
