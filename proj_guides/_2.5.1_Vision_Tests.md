# Vision Tests - Select, Filter & Search Authoring UI (Block 5 Tier 1)

## Setup Instructions
1. Open Unity Editor
2. Navigate to TileStories -> POI Authoring Tool (Shift+P)
3. Ensure LivingRoom config is loaded
4. Switch to the "Search & Filter" foldout in the Global Scene section

## Verification Checklist
Answer each item with "yes/no + what you actually observe":

### 1. Search Index Strategy Dropdown
- [ ] Dropdown shows two options: "keyword_ranked" and "weighted_fields"
- [ ] Default selection is "keyword_ranked"
- [ ] Changing selection triggers _hasUnsavedChanges flag (indicated by unsaved changes warning)

### 2. Ranking & Weights Block (Conditional Visibility)
**When keyword_ranked selected:**
- [ ] "Ranking & Weights" section is visible
- [ ] Help box states: "Weight fields apply only under the 'weighted_fields' strategy. Switch the strategy dropdown above to edit them."
- [ ] All four weight fields (Name weight, Custom field weight, Derived label weight, Others weight) are disabled (grayed out)

**When weighted_fields selected:**
- [ ] "Ranking & Weights" section is visible
- [ ] No help box shown
- [ ] All four weight fields are enabled and editable:
  - [ ] Name weight field accepts numeric input
  - [ ] Custom field weight field accepts numeric input
  - [ ] Derived label weight field accepts numeric input
  - [ ] Others weight field accepts numeric input

### 3. Per-POI Search Keywords Field
- [ ] Expand any POI foldout in the Specific Marker section
- [ ] "Search Keywords" foldout is present
- [ ] Expanding it shows a multi-line text field
- [ ] Text field accepts comma-separated values (e.g., "keyword1, keyword2, keyword3")
- [ ] Editing the field and changing to another POI marks config as unsaved
- [ ] Returning to the POI shows the edited values preserved

### 4. Search & Filter Global Section
- [ ] "Search & Filter" foldout is present in Global Scene section
- [ ] Contains all expected sub-sections:
  - [ ] Search mode dropdown (dynamic/explicit)
  - [ ] Search index strategy dropdown (covered above)
  - [ ] Voice search enabled toggle
  - [ ] Voice match mode dropdown (when voice enabled)
  - [ ] Voice activity indicator style dropdown (when voice enabled)
  - [ ] Recent count field
  - [ ] Suggested source dropdown
  - [ ] Selection highlight toggle
  - [ ] Zoom on select toggle (with density threshold and trigger dropdown when enabled)
  - [ ] Minimap enabled toggle (with visibility and icon style dropdowns when enabled)
  - [ ] Default result view dropdown

### 5. Visual Consistency Checks
- [ ] All dropdowns render correctly with proper text alignment
- [ ] All toggles show clear on/off states
- [ ] Input fields accept appropriate values and reject invalid ones where applicable
- [ ] Section headers use bold styling consistently
- [ ] Help text appears in italic, smaller font below relevant controls
