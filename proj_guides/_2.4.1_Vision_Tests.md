# Cluster Gallery Vision Test Checklist (Tier 1 / Tier 2)

Consumed by Block 5 (Human-in-the-Loop). This is a falsifiable itemized checklist.
Each item requires a YES/NO answer AND a description of what was actually observed.

## Prerequisites
1. Open `Assets/Dev/ClusterGallery/ClusterGalleryScene.unity` in Unity Editor
2. Enter Play Mode
3. Position Scene/Game camera facing the gallery grid so all entries are visible

## Scene context
- The ClusterGalleryScene uses `ClusterGalleryHarness.cs` to instantiate every `ClusterGalleryEntry` from `ClusterGalleryDefinitions.cs` into the real `POI_Cluster` prefab.
- There are 6 entries covering all `cluster_icon_mode` + `member_count` + `label` combinations.
- The harness places them in a 3x2 grid for side-by-side comparison.

## Itemized Checklist

### Entry 1: 2 members (pie_and_count mode)
- [ ] Pie & Count: The pie slices reflect the category mix (religious vs civic proportions)?
- [ ] The "+N" count label shows "+2" exactly?
- [ ] Tap target size >= 44x44px? (MinSizePx = 48)

### Entry 2: 5 members (pie_and_count mode)
- [ ] Pie & Count: The pie slices reflect the 5 members' category mix?
- [ ] The "+N" count label shows "+5" exactly?
- [ ] Size is visibly larger than the 2-member entry?

### Entry 3: 12 members (pie_and_count mode)
- [ ] Pie & Count: Pie slices reflect the category mix?
- [ ] The "+N" count label shows "+12" exactly?
- [ ] Size is clearly larger than the 2-member and 5-member entries? (sizeDelta range 48-112px)

### Entry 4: dominant_category mode
- [ ] Shows the single dominant icon (e.g., IconTemple for religious) + "+N"?
- [ ] NO pie slices visible -- only the icon?

### Entry 5: count_only mode
- [ ] Shows "+N" text only?
- [ ] NO pie slices and NO dominant icon visible?

### Entry 6: All entries
- [ ] Every cluster rect >= 44px (WCAG 2.5.5 minimum tap target)?
- [ ] Cluster vs individual marker fade timing identical? (shared CanvasGroup smoothstep)

## Edge Cases
- [ ] Empty cluster (0 members): Should NOT render (not created in code)
- [ ] Single member: Should NOT render as cluster (handled by ApplyDensityStrategy)

## Screenshots
- Capture one screenshot per entry group -> `Assets/Screenshots/`
- Name format: `ClusterGallery_Vision_<entryCount>members_<date>.png`

## Failure Reporting
For any failed item, report: (1) which entry, (2) what was expected, (3) what was actually observed, (4) a screenshot.
