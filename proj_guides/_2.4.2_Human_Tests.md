# Human-in-the-Loop Test Guide (Block 5)
Protocol per 40-testing §4.6. The human executes these tests on a real device.

## PREREQUISITES
- Unity build configured for Android/iOS
- Device connected, USB debugging enabled
- LivingRoom wall Immersal map deployed
- All 18 POIs active (3 clusters of 6: lamp_*, painting_*, camera_*)
- LOD settings: defaults (config has no explicit lod_settings block; runs with LodSettings defaults: hybrid density response, zoom enabled, 3 bands)

## Spatial reference (from StreamingAssets/LivingRoom/config.json)
| Cluster | Center (world) | Members | Purpose |
|---|---|---|---|
| Lamp | (-1.0, -0.87, -4.18) | lamp_* (6) | Dense region, all 6 within ~0.3m |
| Painting | (-2.0, 0.0, 0.0) | painting_* (6) | Dense region, all 6 within ~0.3m |
| Camera | (-1.93, 0.72, 2.23) | camera_* (6) | Dense region, all 6 within ~0.3m |
| Calibration anchors | (0,0,0) and (4,0,0) | 2 | Define the XR Space X axis |

## TASK A: ARFoundation FOV Spike (§9 of spec)
**Gates the entire zoom feature.** Must pass before zoom is considered verified.

### Step 1: Build & Install
- [ ] Build a development build with ARFoundation + Immersal + zoom enabled
- [ ] Install on device

### Step 2: Walk to LivingRoom wall
- [ ] Hold device steady, let Immersal localize
- [ ] Wait for OnWallLocalised event (check device log)

### Step 3: Test zoom mechanisms
- [ ] Perform pinch-to-zoom gesture on the screen -- does the camera FOV change?
- [ ] Double-tap -- does it zoom in one step? (zoom_tap_step = 1.5x)
- [ ] Third double-tap -- does it return to 1x (base)?
- [ ] If FOV zoom buttons are visible -- tap Zoom In / Zoom Out / Reset

### Step 4: Verify behaviour
- [ ] Camera.fieldOfView changes stick and render correctly?
- [ ] Do markers appear to grow/shrink as expected?
- [ ] Do new markers become visible when zoomed in? (effective-distance hookup)
- [ ] No visual jitter or FOV oscillation?

### Step 5: FOV fallback (if Step 4 failed)
- [ ] If Camera.fieldOfView does NOT work -- test projectionMatrix fallback
- [ ] Log results with timestamps

**Accept:** All zoom mechanisms work on device.
**Fail:** Zoom is broken or visually unusable -- log the error, do NOT ship zoom without this pass.

### On Device (Tier 2):
- [ ] Stand at ~2m from the wall where all 18 POIs are visible
- [ ] Observe:
  - [ ] Do clusters form correctly in dense regions (painting cluster, lamp cluster)?
  - [ ] Are pie slices visible on cluster aggregates?
  - [ ] Does the "+N" count label match the member count?
  - [ ] Does the dominant_category mode show icon + count correctly?
- [ ] Move closer (1m) -- do clusters dissolve into individual markers?
- [ ] Move farther (4m) -- do individual markers merge into clusters?

**Accept:** Cluster gallery matches the spec's visual description.
**Fail:** Any item from the vision checklist fails -- screenshot + describe.

### Setup

- Device build with real LivingRoom Immersal map

### Walk-through
- [ ] Start at far edge (~5m from wall)
- [ ] Slowly walk toward the wall
- [ ] Note at what distance markers first appear (band 1 threshold ~2m)
- [ ] Note whether painting POI (hero, level_1) is always visible vs satellites
